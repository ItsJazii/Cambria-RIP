  Dungeons patch v0.1.0 killed an 'Infinite Poison / Bleed exploit' that let fast attackers sustain damage-over-time forever, and disabled bonus key drops from chests in the same breath.
sources:
  - label: "Patch v0.1.0"
    url: "https://docs.cambria.gg/dungeons/patch-notes/patch-v0.1.0"
---

The fix, verbatim: "Infinite Poison / Bleed exploit - poison switched to a fixed damage budget; bleed timer only refreshes when stack count actually increases. Fast attackers can no longer sustain DoTs indefinitely."

In a dungeon crawler where floors pay out in keys, an unbounded damage loop is not a balance issue, it is a withdrawal method. Bonus key drops from chests were disabled in the same patch.
